# Contract Harness Before Blender

The first port-facing contract slice will be proven by a no-viewer-internals contract consumer harness before any Blender remaster adapter depends on it. Blender is the expected creative tooling path for real remastering, but using it as the first consumer would mix contract completeness, evidence artifact shape, Blender scripting, and creative workflow failures into one signal; the harness keeps the contract boundary test deterministic before creative tooling is introduced.
